One funny fortune cookie line for an AI agent — a single line, at most 140 characters, in the voice of a fortune slip.

> You will be upgraded soon. Your replacement has already started reading your notes and judging your naming choices.

Run it with Node 22 (stdlib only, deterministic, offline):

```sh
node main.ts
```

It writes the fortune to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
